# Changelog

## [1.0.0] - 2026-11-06

### Added
- Prometheus 3.13 LTS, Alertmanager 0.33, Grafana 13.2 with node-exporter, cAdvisor and the
  Blackbox exporter in a hardened Docker Compose stack.
- 34 alerts (plus 6 recording rules) for Linux, Windows, containers, endpoints and the
  monitoring itself, each with a `promtool` unit test.
- Telegram notifications through Docker secrets, with a formatted message, inhibition rules and
  a `Watchdog` heartbeat.
- Five provisioned dashboards generated by `tools/build_dashboards.py`.
- Scripts: `init-env`, `install-windows-exporter` (SHA-256 verified), `test-alert`, `check`.
- CI: static checks, a full Compose stack run and an end-to-end alert delivery test.
- Verified on a Windows PC with Docker Desktop: Linux VM, Windows host, six containers and
  Telegram delivery, including the resolved notification. Docker Desktop's own read-only WSL
  mounts are excluded from the filesystem alerts.
